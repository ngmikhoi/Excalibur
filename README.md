# Assignment 2: The Sword in the Stone
**Course:** Programming Fundamentals (CO1027)

## Overview
This assignment is part of the **Programming Fundamentals (CO1027)** course at **Ho Chi Minh City University of Technology**. It involves implementing a program to manage an **Army of Knights** and their journey to defeat **Ultimecia**. 

## Tasks
The program simulates an **Army of Knights** preparing for battle against Ultimecia. The program must process input files containing details about the knights and events affecting their journey.
By completing this assignment, students will review and strengthen their knowledge in:  
- **Pointers**  
- **Object-Oriented Programming (OOP)**  
- **Singly Linked Lists**
